# Where these came from

These product shots were ported from the local.ai web catalog
(`local-ai-web/public/images/hardware/`) together with its id → file mapping.
Only the files the app actually references are copied here; see
`frontend/src/features/configure/hardware-image.tsx` for the mapping and for the
line-drawing glyph that stands in for any device without a shot.

# Mac mini M4 image

`m4-pro-mac-mini.png` is a transparent PNG rendered from [Apple Mac Mini M4.svg](https://commons.wikimedia.org/wiki/File:Apple_Mac_Mini_M4.svg) by LoMit. The source is dedicated to the public domain under CC0 1.0.

# MacBook Pro and Mac Studio images

`m4-max-macbook-pro-cutout.png` and `m3-ultra-mac-studio-cutout.png` are tight transparent cutouts derived from the respective Apple Store product shots already used by the site. They retain the shared MacBook Pro and Mac Studio chassis render; configuration-specific identity remains in the measured catalog data, not the image.
